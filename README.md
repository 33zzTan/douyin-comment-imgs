# 抖音评论图片直取

一个 Tampermonkey 用户脚本：把抖音**网页版评论区**里的图片直接抓出来保存，**不依赖页面渲染**。

> 为什么需要它：网页版评论区保存下来的图，角落会带「抖音号：xxx」水印；有些图片在页面上甚至根本显示不出来。本脚本不碰页面上的图，而是直接监听评论接口响应，从 JSON 的 `image_list` 里取原图地址。

## 功能

- **评论图片一键保存**：缩略图上悬停出现下载图标，点一下直接存，不用打开大图、不用右键另存
- **不受页面渲染限制**：只要接口给了数据，页面上显示不出来的图也能取到
- **三种保存格式**：原图（webp，零损失）/ JPG（体积小）/ PNG（无损但偏大）
- **悬停放大预览**：鼠标移到缩略图上，旁边弹出大图并显示真实像素尺寸
- **换视频自动清空**：从 A 视频切到 B 视频，列表自动归零，不会混
- **3 列网格面板**：悬停「评论图」按钮自动展开，移开自动收起

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（Edge / Chrome / Firefox 均可）
2. 点这里安装脚本：[douyin-comment-imgs.user.js](https://raw.githubusercontent.com/33zzTan/douyin-comment-imgs/main/douyin-comment-imgs.user.js)
   （也可以在 Tampermonkey 里新建脚本，把 js 文件内容整段粘进去）
3. 打开 <https://www.douyin.com>

## 使用

1. 打开任意作品页，把**评论区往下滚**（滚到底会触发翻页，脚本靠这个抓数据）
2. 右下角出现「评论图 N」，鼠标移上去展开面板
3. 缩略图上悬停 → 看大图；点一下 → 直接下载

下载的文件名形如 `dy_64543933_01.jpg`（`评论ID后8位_序号`）。

第一次下载时 Tampermonkey 会询问是否允许跨域，选「总是允许」。

## 原理

```
抖音网页版 → XHR/fetch 请求 /aweme/v1/web/comment/list/
                    ↓
        脚本 hook 住响应（XMLHttpRequest + fetch 双保险）
                    ↓
        递归遍历 JSON，凡是带 image_list 的节点就抽 URL
                    ↓
        按「无模板段 > 模板段」打分排序，选最接近原图的地址
                    ↓
        GM_xmlhttpRequest 下载 → canvas 转 JPG/PNG → 存盘
```

关键点：**不解析 DOM、不等图片渲染**。页面渲不渲染，跟拿不拿到数据是两件事。

## 已知限制

- **二级回复里的多图取不到**：实测网页版 `comment/list/reply` 接口对这类回复直接返回 `image_list: []`，是服务端过滤，客户端无解。（用同样参数在 Python 里加签名重放，结果相同。）
- 必须先滚动评论区，否则不会触发接口请求。
- 依赖抖音 web 接口字段名，接口改版后可能需要跟进。
- 只处理图片，不含视频/图集。

## 面板显示 0 怎么办

1. 确认评论区已经滚动过，且接口确实返回了评论
2. F12 → Console，看有没有 `[dci]` 开头的日志
3. 有 `[dci] 响应 ... 评论数 N` 但没涨 → 说明这批评论确实没图
